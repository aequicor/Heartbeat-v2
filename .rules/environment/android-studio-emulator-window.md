# Поверхность Android Emulator в Android Studio

## Условия применимости

На macOS ADB видит запущенный из CLI тестовый AVD. Android Studio показывает
его в Device Manager, но в Running Devices экран отсутствует.

## Действие

Останови только запущенный для текущей задачи AVD и запусти этот же профиль
из Device Manager. Когда Android загрузится, открой Running Devices и
установи проверяемую сборку на заново подключившийся эмулятор. Для
координатных действий оставь панель Running Devices закреплённой в
основном окне Android Studio.

## Границы

Перезапуск нужен для ручных взаимодействий с экраном. Для проверок через ADB
можно использовать уже подключённое устройство без перезапуска.
