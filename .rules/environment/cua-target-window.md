# Проверка целевого окна при захвате Windows

## Применимость

Ручная проверка Windows через `node_repl` и `@oai/sky`, когда Heartbeat терял фокус
или менялся размер окна.

## Ограничение

Наблюдалось несоответствие между выбранным `Window` и возвращённым кадром:
метаданные называли Heartbeat, но изображение показывало другое окно либо прежний размер.
Ввод по такому кадру отклонялся как попадание в другой процесс. Повторный захват после
явной активации целевого окна возвращал актуальную область.

## Требуемое поведение

При смене фокуса или несоответствии кадра сначала активируй ранее выбранное единственное
целевое окно, затем получи новое состояние. До ввода визуально проверь приложение и размер
снимка. Используй только новые координаты и screenshotId; не повторяй действие по старому кадру.
Если активация не устраняет несоответствие, останови ввод и сообщи ограничение.

## Исключения

Не активируй окно и не продолжай ввод после остановки Computer Use оператором.
