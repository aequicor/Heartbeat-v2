# Замеры времени кадра на Android Emulator

При профилировании прокрутки на macOS зафиксируй графический backend запущенного AVD вместе с
разрешением и частотой экрана. Режим `auto` в конфигурации AVD допускает программный рендеринг.
Проверь строку `GLES` в `adb -s <serial> shell dumpsys SurfaceFlinger`.

Если вывод указывает SwiftShader или lavapipe, используй такой прогон для диагностики программного
рендера. Для оценки аппаратного пути сравни одинаковые жесты на отдельном эмуляторе с
`-gpu host`. Проверь Metal или имя аппаратного GPU в гостевом SurfaceFlinger. Выбирай устройство
по serial и сохраняй рабочий AVD и данные пользователя. Если аппаратное ускорение недоступно,
укажи backend рядом с результатами.

Для сопоставимых измерений прогрей экран, приведи IME в одинаковое состояние, сбрось статистику
целевого пакета и сними `dumpsys gfxinfo <package> framestats` за один и тот же интервал ввода и
прокрутки. Системный экран со сходной прокруткой помогает отделить задержки эмулятора от задержек
приложения. На физическом устройстве выбор backend эмулятора пропускается.
