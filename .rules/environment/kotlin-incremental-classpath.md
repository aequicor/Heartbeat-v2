# Снимок classpath в инкрементальной компиляции Kotlin JVM

## Условия применимости

Задача Gradle `compileKotlinJvm` потребляющего модуля завершается сообщением
`The following FqNames can't be derived from DirtyData.dirtyLookupSymbols`
после изменения вложенного типа в зависимом модуле. Стек содержит
`ClasspathChangesComputer`.

## Действие

Выполни `clean` только для модуля с упавшей задачей, затем повтори исходную
сборку обычной командой. Очистка сбрасывает сохранённый снимок classpath
потребляющего модуля.

## Границы

Если после очистки компилятор выдаёт диагностику по исходникам, исправляй её
по месту. Сохраняй инкрементальную компиляцию и ограничивай очистку упавшим
модулем.
