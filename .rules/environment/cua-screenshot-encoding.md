# Кодирование снимков при анализе растеризации

## Применимость

Пиксельное сравнение сглаживания, цветной каймы и резкости по снимкам Windows из CUA.

## Условие

`cua_repl` / `app.getScreenshot()` возвращает закодированные байты. В проверенной сессии
они имели сигнатуру JPEG (`FF D8 FF`), хотя сохранение с расширением `.png` было допустимо.
JPEG добавляет смягчение и цветовые артефакты, поэтому такой снимок нельзя считать эталоном
пикселей рендерера или напрямую сравнивать с исходным PNG для оценки сглаживания.

## Требуемое поведение

Для пиксельных измерений сначала установи реальный формат по сигнатуре, а не по расширению.
Сохраняй снимок с соответствующим расширением. Используй PNG без потерь из тестового рендера
или исходный PNG оператора для анализа краёв букв. Перекодирование JPEG в PNG не восстанавливает
исходные пиксели. JPEG подходит для проверки компоновки и взаимодействий, но не для доказательства
типа сглаживания или степени размытия.

## Исключения

Для обычной навигации по UI дополнительная проверка формата не нужна. Если инструмент действительно
возвращает изображение без потерь, ограничение JPEG к нему не относится.
