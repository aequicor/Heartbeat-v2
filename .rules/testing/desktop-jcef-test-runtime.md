# Тест локальных диаграмм на Desktop

Если установлены несколько JetBrains Runtime 25, Gradle может выбрать для JVM-теста
вариант без JCEF. Упаковка приложения подбирает JBR с JCEF отдельно.

При `NoClassDefFoundError` для `org.cef` сверь исполняемый файл тестового процесса
в логе Gradle `--info` и наличие модуля `jcef` в этом JBR. Для проверки на runtime
упаковки можно запустить скомпилированный JUnit-тест напрямую его исполняемым файлом
`bin/java`, указав `--add-modules jcef` и файл аргументов classpath из строки запуска
того же Gradle-теста. Для теста живых диаграмм требуется `HB_DIAGRAM_RUNTIME_SMOKE=1`.

При успешной загрузке JCEF исследуй ошибки рендерера и его дочернего процесса отдельно.
