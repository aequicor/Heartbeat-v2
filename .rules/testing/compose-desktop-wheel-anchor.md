# Якорь чтения и инерция колеса в Compose Desktop

Для тестов прокрутки с ImageComposeScene в Compose Multiplatform 1.12.2.

- Для проверки неподвижного фрагмента дождись, когда LazyListState.isScrollInProgress станет false
  после отправленного события колеса. Одиночный скачок тестовых часов может лишь запустить анимацию.
- Для проверки обновления во время инерции проиграй один и тот же жест с одинаковыми тактами
  в двух сценах. В одной сцене обнови текст во время движения. В обеих дождись окончания жеста
  и сравни положение курсора одной и той же исходной строки в координатах окна.
- При асинхронной подготовке текста перед сравнением дождись нового фрагмента в семантике.
  Измерение сразу после публикации StateFlow может относиться к предыдущему содержимому.
- Для заранее подготовленных узлов проверь `isPlaced` у узла и его предков. Для видимого
  фрагмента проверь также пересечение его границ с окном.
- При проверке пропуска отрисовки за пределами экрана прокрути к ранее скрытому фрагменту
  и обратно. Проверь пиксели текста в обоих положениях. Сохранённый слой может остаться пустым
  при корректных координатах и рабочем выделении.

Эти условия относятся к проверкам сохранения места чтения. Для отдельной проверки реакции
на первый импульс колеса измеряй нужный кадр жеста.

В живом окне macOS выполняй перемещение, нажатие, перетаскивание и отпускание одним
экземпляром `java.awt.Robot`. При смене экземпляра между наведением и нажатием событие может
прийти по предыдущим координатам. Доставленные события перетаскивания сами по себе не доказывают
захват ползунка. Проверь изменение позиции списка и границы прокрутки после отпускания.
