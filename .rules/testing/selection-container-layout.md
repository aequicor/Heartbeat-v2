# Раскладка чанков в SelectionContainer

## Применимость

Compose UI-тест выводит несколько текстовых узлов через SelectionContainer,
например чанки длинного plain thinking.

## Требуемое поведение

Воспроизводи реальный контейнер внутри SelectionContainer явно: для вертикальных
чанков нужен Column. SelectionContainer сам не задаёт вертикальный порядок:
прямые текстовые дети могут накладываться, а высота равна максимуму вместо суммы.
Наличие обоих узлов в semantics не доказывает правильную геометрию.

Проверено на границе 32 строк: следующий чанк имел нативную высоту 40,
но фикстура оставалась высотой 640; Column внутри SelectionContainer дал 680.

## Исключения

Один дочерний layout или намеренное наложение не требуют дополнительного Column.
