# Показ кадров окна Compose Desktop на macOS

При проверке рывка в движущемся интерфейсе измеряй длительность `onRender` и смену изображения
окна отдельно. Skiko может не запрашивать новый кадр, пока содержимое неподвижно.

- Для наблюдения через ScreenCaptureKit ограничь захват проверяемым окном. Используй метку
  WindowServer `displayTime` и статус буфера. Сравни пиксели движущейся области в последовательных
  полных буферах. Промежуток без полученных буферов оставляет смену изображения неопределённой.
- Если в исследуемом интервале нет движения, воспроизведи сценарий также с непрерывно
  меняющимся маркером в той же Compose-сцене. Проверь обычную частоту его обновлений до и после
  операции. Время появления содержимого измеряй отдельно в обычном окне по первому кадру
  с ожидаемым видимым результатом.
- Обход семантического дерева для проверки полноты содержимого выполняй после измерения.
  Даже обход за пределами таймера `onRender` занимает поток окна перед следующим кадром.

`displayTime` относится к изображению оконного сервера. Для времени физического отклика панели
нужно внешнее измерение.
