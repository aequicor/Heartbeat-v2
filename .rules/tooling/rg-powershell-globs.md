# Шаблоны путей rg в PowerShell

## Применимость

Поиск `rg` на Windows из PowerShell с шаблоном имени файла.

## Ограничение и решение

PowerShell не раскрывает `*` в аргументе пути для нативного `rg`. Путь вида
`components/AuroraWork*.kt` передаётся буквально и завершается ошибкой Windows 123.
Проверенный вариант: передать существующий каталог и шаблон через `-g`:

```powershell
rg -n -g 'AuroraWork*.kt' 'pattern' features/ai-studio/ui/compose/src
```

Для отбора имён из `rg --files` также используй `-g`, если достаточно шаблона имени.
Не повторяй тот же поиск с `*` в позиционном пути после этой ошибки.

## Исключения

Полные пути без шаблонов передавай обычными аргументами. Правило не относится к
нативным PowerShell cmdlet, которые сами обрабатывают wildcard.
