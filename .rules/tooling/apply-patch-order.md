# Порядок блоков apply_patch

## Применимость

Один вызов `apply_patch` меняет несколько участков одного файла.

## Требуемое поведение

Расположи блоки `@@` в порядке участков исходного файла, от начала к концу. Поиск следующего
блока продолжается после предыдущего: возврат к более раннему участку вызывает ошибку проверки,
даже если его контекст совпадает с файлом.

Если ошибка возникла после перестановки блоков, сначала сверь их порядок с исходным файлом.

## Исключения

Отдельные вызовы и блоки для разных файлов не требуют общего порядка строк.
