# Инструкции для документации

- Храни спецификации в `specs/`. Используй формат `HB-<область>-<номер>` для требований. Для каждого требования укажи источник и способ проверки.
- Добавляй пользовательские страницы в меню `mkdocs.yml`. Между страницами сайта используй относительные Markdown-ссылки. Для файлов вне `docs/` используй ссылки на GitHub.
- Проверяй изменения строгой сборкой. Выходной каталог `site/` генерируется при сборке.

Из корня репозитория выполни команды в окружении Python 3.12.

```shell
python -m pip install -r requirements-docs.txt
python -m mkdocs build --strict
python -m mkdocs serve
```

Сборка должна завершиться без предупреждений. При предпросмотре проверь изменённые страницы, навигацию и поиск.
