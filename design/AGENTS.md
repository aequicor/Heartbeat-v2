# Инструкции для прототипирования

1. Определи затронутые платформы и пользовательские сценарии. Зафиксируй результат оценки UI/UX в плане.
2. Если интерфейс меняется, подготовь макет в [Pencil](https://www.pen.dev/) и сохрани `.pen` в этом каталоге. Используй инструменты Pencil для чтения, редактирования и проверки макетов.
3. Покажи оператору основной сценарий и применимые состояния загрузки, отсутствия данных и ошибок. Укажи, где поведение различается между платформами.
4. Запиши согласованный вариант и путь к макету в плане. После открытия draft PR добавь макет отдельным логическим шагом. При изменении согласованного сценария повторно согласуй его с оператором.
