# Инструкции для прототипирования

1. Определи затронутые платформы и пользовательские сценарии. Зафиксируй результат оценки UI/UX в плане.
2. Если интерфейс меняется, примени скил [unslop](../.agents/skills/unslop/SKILL.md). Проведи аудит по
   `references/signs.md` и составь направление из пяти строк: продукт, характер, мир, моменты,
   сигнатура. Запиши направление в план и согласуй его с оператором до реализации.
3. Подготовь макет в [Pencil](https://www.pen.dev/) и сохрани `.pen` в этом каталоге. Выполняй
   проходы unslop в макете по порядку: отступы, цвет, иконки, текст, типографика, компоновка, детали.
   Сборка HTML, снимки страниц, генерация изображений и story-видео к этапу макетов не относятся.
4. Покажи оператору основной сценарий и применимые состояния загрузки, отсутствия данных и ошибок.
   Укажи, где поведение различается между платформами.
5. При реализации и проверке Compose Multiplatform экранов применяй правила оформления из unslop.
   Механика HTML/CSS, снимки страниц и story-видео к Compose не переносятся.
6. Запиши согласованный вариант и путь к макету в плане. После открытия draft PR добавь макет
   отдельным логическим шагом. При изменении согласованного сценария повторно согласуй его с
   оператором.
